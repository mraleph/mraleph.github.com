<section id="about" aria-label="About me">
  <h2>About</h2>
  <div>
    <p>I am a software engineer interested in design and implementation of programming languages, compilers, runtime systems, low-level and systems programming, performance optimization. I occasionally give <a href="/talks/index.html" class="equity-caps">talks</a> about these topics</p>
    <p>Currently, I work at Google as an overall technical lead for the <a class="equity-caps" href="https://dart.dev" target="_blank" rel="noreferrer noopener" aria-label="Dart (opens in a new tab)" title="Dart">Dart</a> programming language. I joined the team in 2012 to design and implement a speculative optimizing JIT in the Dart VM. The compiler pipeline that we have created later became the foundation for Dart's native AOT compiler.</p>
    <p>In 2016 I had a brief stint at DeepMind maintaining <a class="equity-caps" target="_blank" rel="noreferrer noopener" href="https://github.com/luajit/luajit">LuaJIT</a> for them.</p>
    <p>Before joining Dart I was part of the <a class="equity-caps" target="_blank" rel="noreferrer noopener" href="https://v8.dev" aria-label="V8 (opens in a new tab)" title="V8">V8</a> JavaScript engine team at Google. Here I contributed to <a class="equity-caps" target="_blank" rel="noreferrer noopener" href="https://blog.chromium.org/2010/12/new-crankshaft-for-v8.html" aria-label="Crankshaft (opens in a new tab)" title="Crankshaft">Crankshaft</a> and efforts to modernize V8's <a class="equity-caps" target="_blank" rel="noreferrer noopener" href="https://blog.chromium.org/2011/11/game-changer-for-interactive.html">GC</a>. I have been involved in <a  class="equity-caps" target="_blank" rel="noreferrer noopener" href="https://chromium.googlesource.com/v8/v8/+/main/include/cppgc/README.md">OilPan</a> - effort to replace reference counting based memory management in <a class="equity-caps" target="_blank" rel="noreferrer noopener" href="https://www.chromium.org/blink/">Blink</a> with an precise-on-heap mark-and-sweep GC.</p>
    <p>I started my carrier working on <a class="equity-caps" target="_blank" rel="noreferrer noopener"  href="https://en.wikipedia.org/wiki/Excelsior_JET">Excelsior JET</a> a proprietary Java VM with an AOT compiler.</p>
