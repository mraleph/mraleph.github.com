description: |
    JavaScript performance remains an area of focus for all major browser vendors. Each day VM-engineers across the globe pump their expertise into JavaScript engines powering client and server-side code alike.
    However our understanding of JavaScript engine internals does not always keep up with those internals.</p>
    This talk tries to rectify this lag and demonstrate that knowledge of implementation details is crucial not only to writing fast JavaScript code but even to simply measuring the difference between fast and slow.
